# 🎯 TeddyBear'sRoom 타겟 고객 인터뷰 가이드

**작성일**: 2025-11-20
**목적**: 페르소나 검증 및 제품-시장 적합성(PMF) 탐색
**방법론**: Jobs-to-be-Done (JTBD) 프레임워크 기반 심층 인터뷰

---

## 📋 **1. 인터뷰 개요**

### 1.1 인터뷰 목표

1. **페르소나 검증**: 시장 조사에서 정의한 타겟 고객 가정 검증
2. **Pain Point 구체화**: 기존 성인용품 쇼핑 경험의 문제점 발견
3. **Jobs 발견**: 고객이 성인용품을 "고용"하는 진짜 이유 파악
4. **차별화 전략 검증**: "파스텔 + 감성 + 페티시 전문화" 전략 반응 확인
5. **MVP 제품군 선정**: 초기 출시 제품 우선순위 결정

### 1.2 타겟 인터뷰 대상 (5~10명)

**Primary 페르소나**:
- **연령**: 25~40대 여성
- **성향**: 자기 표현에 적극적, 감성적 소비 선호
- **라이프스타일**:
  - SNS 활동 활발 (인스타그램, 핀터레스트 등)
  - 감성적 브랜드 선호 (올리브영, 무신사, 29CM 등)
  - Self-care, 웰니스에 관심
- **구매 경험**:
  - 성인용품 온라인 구매 경험 있음 (최소 1회 이상)
  - 기존 쇼핑몰 이용 경험 보유

**Secondary 페르소나** (2~3명 포함):
- 페티시 관심층 (특정 선호도 보유)
- 커플 구매 경험자
- 남성 고객 (비교군)

### 1.3 인터뷰 형식

- **방식**: 1:1 개별 인터뷰 (그룹 인터뷰 지양)
- **시간**: 45~60분
- **장소**: 온라인 (Zoom, Google Meet) 또는 오프라인 카페 (편안한 분위기)
- **보상**: 스타벅스 기프티콘 1만원 + 런칭 시 할인 쿠폰
- **녹음**: 동의 후 녹음/녹화 (분석 목적)

## 🔍 **2. JTBD 프레임워크 기반 질문 설계**

### 2.1 JTBD 핵심 개념

> **"고객은 제품을 사는 것이 아니라, 특정 업무(Job)를 완료하기 위해 제품을 고용한다."**
> - Clayton Christensen

**핵심 질문**: "왜 성인용품을 구매하셨나요?" (X)
**JTBD 질문**: "이 제품을 고용해서 무엇을 이루려고 하셨나요?" (O)

### 2.2 인터뷰 구조 (5단계)

```
1. Warm-up (5분): 라포 형성, 편안한 분위기 조성
2. 과거 경험 탐색 (15분): 최근 구매 경험 회상
3. Jobs 발굴 (15분): 진짜 동기와 목표 파악
4. Pain Points (10분): 불편했던 점, 방해물 식별
5. 이상적 경험 (10분): 원하는 미래 상태 탐색
```

## 💬 **3. 인터뷰 질문 스크립트**

### Phase 1: Warm-up & Context Setting (5분)

**목표**: 신뢰 형성, 편안한 분위기 만들기

1. **시작 인사**
   > "안녕하세요! 오늘 시간 내주셔서 정말 감사합니다. 저는 새로운 온라인 쇼핑몰을 준비 중인 [이름]입니다. 오늘 인터뷰는 정답을 찾는 게 아니라, [이름]님의 솔직한 경험과 생각을 듣기 위한 시간이에요. 편하게 이야기해주시면 됩니다."

2. **동의 확인**
   > "녹음/녹화에 동의해주시나요? 분석 목적으로만 사용되며, 개인정보는 완전히 익명 처리됩니다."

3. **배경 질문**
   - "평소 온라인 쇼핑을 자주 하시는 편인가요? 어떤 쇼핑몰을 주로 이용하시나요?"
   - "SNS는 어떤 걸 주로 사용하시나요? (인스타, 핀터레스트 등)"

---

### Phase 2: 과거 경험 탐색 (15분)

**목표**: 최근 구매 경험 회상, 구체적 상황 파악

#### 2-1. 타임라인 탐색 (Timeline Exploration)

4. **최근 구매 경험 회상**
   > "성인용품을 가장 최근에 구매하신 경험을 떠올려주세요. 언제, 어디서 구매하셨나요?"

   - Follow-up: "그때 상황을 좀 더 구체적으로 설명해주실 수 있나요?"
   - Follow-up: "처음 구매를 생각하게 된 계기는 무엇이었나요?"

5. **구매 전 과정 (Before)**
   > "구매를 결정하기 전에 어떤 고민을 하셨나요?"

   - Follow-up: "정보는 어디서 찾으셨나요? (검색, SNS, 친구 추천 등)"
   - Follow-up: "여러 쇼핑몰을 비교하셨나요? 어떤 기준으로 선택하셨나요?"
   - Follow-up: "구매를 망설이게 만든 요소가 있었나요?"

6. **구매 중 과정 (During)**
   > "실제로 쇼핑몰에서 제품을 고르는 과정은 어땠나요?"

   - Follow-up: "사이트 분위기가 어땠나요? 느낌이 좋았나요/불편했나요?"
   - Follow-up: "제품 정보가 충분했나요? 부족했던 정보는?"
   - Follow-up: "결제 과정에서 불편한 점은 없었나요?"

7. **구매 후 과정 (After)**
   > "제품을 받았을 때의 경험은 어땠나요?"

   - Follow-up: "포장은 어땠나요? 프라이버시 보호가 잘 되었나요?"
   - Follow-up: "제품 품질은 기대와 비교해서 어땠나요?"
   - Follow-up: "재구매 의향이 있으신가요? 같은 쇼핑몰을 다시 이용하실 건가요?"

---

### Phase 3: Jobs Discovery (15분)

**목표**: 진짜 동기, 달성하려는 목표 파악

#### 3-1. JTBD 핵심 질문

8. **Job 발굴**
   > "그 제품을 구매해서 궁극적으로 이루고 싶었던 게 무엇이었나요?"

   - Follow-up: "그 목표를 이루기 위해 다른 방법도 고려하셨나요?"
   - Follow-up: "왜 그 제품이 최선의 선택이라고 생각하셨나요?"

9. **정황 (Context) 탐색**
   > "그 결정을 내리게 된 상황이나 배경을 좀 더 자세히 말씀해주실 수 있나요?"

   - Follow-up: "그때 특별히 필요했던 이유가 있었나요? (특별한 날, 스트레스, 호기심 등)"
   - Follow-up: "혼자 결정하셨나요? 누군가와 상의하셨나요?"

10. **절충 (Trade-offs)**
    > "완벽하진 않지만 '이 정도면 괜찮다'라고 타협했던 부분이 있나요?"

    - Follow-up: "이상적으로는 어떤 제품/서비스를 원하셨나요?"
    - Follow-up: "왜 그 이상적인 것을 찾지 못하셨다고 생각하세요?"

11. **품질 정의**
    > "본인에게 '좋은 성인용품 쇼핑 경험'이란 어떤 건가요?"

    - Follow-up: "가장 중요하게 생각하는 3가지 요소는 무엇인가요?"
    - Follow-up: "품질, 가격, 디자인, 프라이버시 중 우선순위는?"

---

### Phase 4: Pain Points & Barriers (10분)

**목표**: 기존 경험의 문제점, 방해물 식별

#### 4-1. 불편 사항 파악

12. **쇼핑 과정의 불편함**
    > "성인용품을 온라인으로 구매할 때 가장 불편했던 점은 무엇이었나요?"

    - Follow-up: "사이트 디자인/분위기가 불편했던 적이 있나요? 어떤 점이?"
    - Follow-up: "정보가 부족해서 망설였던 적이 있나요? (사이즈, 사용법, 리뷰 등)"
    - Follow-up: "프라이버시 걱정 때문에 구매를 포기한 적이 있나요?"

13. **신뢰 문제**
    > "쇼핑몰을 신뢰하기 어려웠던 경험이 있나요?"

    - Follow-up: "가짜 제품, 품질 불량 우려는 없었나요?"
    - Follow-up: "고객 리뷰를 신뢰하셨나요? 조작된 것 같다는 느낌은?"

14. **감성적 불만**
    > "쇼핑 과정에서 기분이 안 좋았던 적이 있나요?"

    - Follow-up: "사이트가 너무 노골적이거나 저속하다고 느낀 적은?"
    - Follow-up: "쇼핑이 즐겁지 않고 스트레스였던 이유는?"

15. **커뮤니티 부재**
    > "다른 사용자들과 정보를 공유하고 싶었던 적이 있나요?"

    - Follow-up: "커뮤니티나 Q&A 기능이 있었다면 도움이 되었을까요?"
    - Follow-up: "성인용품에 대해 솔직하게 이야기할 수 있는 공간이 필요하다고 느낀 적은?"

---

### Phase 5: Ideal Future State (10분)

**목표**: 이상적 경험 탐색, 차별화 전략 검증

#### 5-1. 이상적 쇼핑 경험

16. **꿈의 쇼핑몰**
    > "만약 본인이 성인용품 쇼핑몰을 만든다면, 어떤 모습일까요?"

    - Follow-up: "어떤 분위기/디자인이면 좋을까요?"
    - Follow-up: "어떤 기능이 꼭 있었으면 하나요?"
    - Follow-up: "다른 쇼핑몰과 차별화되는 점은?"

17. **감성 브랜딩 반응 테스트** (⚠️ 핵심 검증)
    > "만약 성인용품 쇼핑몰이 파스텔 컬러에 부드럽고 귀여운 디자인이라면 어떨 것 같으세요?"

    - Follow-up: "그런 분위기가 편안할 것 같나요? 아니면 어색할 것 같나요?"
    - Follow-up: "기존 쇼핑몰과 비교해서 더 이용하고 싶으신가요?"
    - Follow-up: "너무 가벼워 보여서 신뢰가 떨어질 것 같나요?"

18. **페티시 전문화 반응 테스트** (⚠️ 핵심 검증)
    > "만약 특정 스타일이나 선호도(페티시)를 가진 사람들을 위한 전문 코너가 있다면 관심이 있으신가요?"

    - Follow-up: "본인에게 맞는 제품을 큐레이션 받을 수 있다면 도움이 될까요?"
    - Follow-up: "그런 전문성이 오히려 부담스럽거나 좁아 보일까요?"

19. **구독 멤버십 반응 테스트** (⚠️ 핵심 검증)
    > "매달 일정 금액(예: 19,900원)을 내고 혜택을 받는 구독 서비스가 있다면 관심이 있으신가요?"

    - Follow-up: "어떤 혜택이 있다면 가입하실 건가요? (할인, 포인트, 무료배송, 기부 등)"
    - Follow-up: "구독료가 너무 비싸다고 느끼는 가격대는 얼마인가요?"

20. **커뮤니티 기능**
    > "사용자들이 솔직한 리뷰를 공유하고 질문할 수 있는 커뮤니티가 있다면 참여하실 건가요?"

    - Follow-up: "익명으로 활동할 수 있다면?"
    - Follow-up: "어떤 주제의 콘텐츠가 있으면 좋을까요?"

21. **마무리 질문**

### 4.3 스크리닝 질문 (사전 필터링)

모집 후 간단한 사전 설문으로 적합한 참가자 선별:

3. **성인용품 온라인 구매 경험**: 있음 / 없음

5. **주로 이용하는 쇼핑몰**: (자유 응답)
6. **쇼핑 시 가장 중요하게 생각하는 요소**: 가격 / 품질 / 디자인 / 프라이버시 / 브랜드 철학 / 기타

**선정 기준**:
- 25~40대 여성 우선
- 구매 경험 1회 이상
- "디자인", "브랜드 철학", "프라이버시" 중 하나 이상 선택한 사람 우선

- [ ] 메모 준비 (노트북/노트)
- [ ] 편안한 분위기 조성 (음료 준비, 조명 확인 등)

### 5-3. 인터뷰 중

- [ ] 동의서 서명 받기
- [ ] 녹음/녹화 시작
- [ ] 질문에만 집중하지 말고 응답자가 리드하게 함
- [ ] "왜?"를 최소 3번 물어보기 (5 Whys 기법)
- [ ] 비언어적 신호 관찰 (표정, 망설임, 강조 등)

### 5-4. 인터뷰 후 (당일)

- [ ] 메모 정리 (핵심 인사이트, 흥미로운 발언 기록)
- [ ] 녹음 파일 백업 (Google Drive, Notion 등)
- [ ] 참가자에게 감사 메시지 + 기프티콘 발송

## 📈 **6. 분석 프레임워크**

### 6-1. 데이터 정리 방법

인터뷰 후 다음 항목별로 정리:

| 항목 | 내용 |
|------|------|
| **Jobs** | 고객이 달성하려는 목표, 고용 이유 |
| **Pain Points** | 기존 경험의 불편함, 방해물 |
| **정황 (Context)** | 구매 결정의 배경, 상황 |
| **절충 (Trade-offs)** | 타협했던 부분, 미충족 니즈 |
| **이상적 경험** | 원하는 미래 상태 |
| **차별화 반응** | 파스텔/페티시/구독에 대한 반응 |

### 6-2. 인사이트 추출

- **패턴 찾기**: 5명 이상이 언급한 공통 Pain Point
- **극단값 주목**: 특이하지만 강렬한 의견 (Edge Case)
- **감정 분석**: 긍정/부정 감정 포인트 식별
- **가설 검증**: 시장 조사에서 세운 가정이 맞는지 확인

### 6-3. 결과 문서화

3. **MVP 제품 리스트**: 우선순위 기반 제품군
4. **차별화 전략 보완안**: 인터뷰 피드백 반영

## ✅ **7. 성공 기준**

인터뷰가 성공적이었는지 판단하는 기준:

1. **질적 기준**
   - [ ] 최소 3개 이상의 공통 Pain Point 발견
   - [ ] Jobs가 명확하게 정의됨 (5 Whys를 통해)
   - [ ] 이상적 경험에 대한 구체적 묘사 확보
   - [ ] 차별화 전략(파스텔/페티시/구독)에 대한 솔직한 반응 확보

2. **양적 기준**
   - [ ] 5~10명의 타겟 고객 인터뷰 완료
   - [ ] 평균 인터뷰 시간 45분 이상
   - [ ] 베타 테스터 참여 의향 50% 이상

3. **액션 가능성**
   - [ ] MVP 제품군 우선순위 결정 가능
   - [ ] 디자인 시스템 방향성 확정 가능
   - [ ] 마케팅 메시지 초안 작성 가능
