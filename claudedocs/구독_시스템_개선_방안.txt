## 2. 현재 구독 시스템 분석

### 2.1 기존 2-Tier 구조

엔트리 (19,900원/월)
├─ 구독료의 5% 기부 (약 995원)
├─ 구매금의 5% 포인트 적립
├─ 스탠다드 Try & Buy 박스 (원가 3,500원)
└─ 마케팅 메시지: "의미 있는 소비"

프리미엄 (29,900원/월)
├─ 구독료의 10% 기부 (약 2,990원)
├─ 구매금의 10% 포인트 적립
├─ 프리미엄 Try & Buy 박스 (원가 5,000원)
├─ 추가 혜택: 우선 고객 지원, 신제품 얼리 액세스
└─ 마케팅 메시지: "혜택은 엔트리의 두 배! 가격은 혜택의 절반만!"

├─ 분기별 투표로 재단 선택

Try & Buy 랜덤 박스

├─ 조건부 수령: 포인트 5% (구매해야 가치 발생)

프리미엄 29,900원

### 3.2 문제 2: 즉시 혜택 부재 (Critical Flaw #2)

현재 혜택 구조의 문제:
├─ 포인트: 구매해야 가치 발생 (미래형 혜택)
├─ 기부: 내가 얻는 게 아님 (이타적 가치)
├─ 박스: 6개월이면 신선함 소진 (감가상각)
└─ 결론: 지금 당장 얻는 게 없음

포인트 시스템의 악순환:
1. 구독료 내고
2. 포인트 받으려면 물건 사고
3. 포인트 쓰려면 또 물건 사야 함
4. 결국 "더 많이 소비"하게 만드는 시스템

심리적 가치의 감가상각:
├─ 초기 3개월: 심리적 가치 100%
├─ 6개월: 50%
├─ 12개월: 20%
└─ 결국 남는 건 "경제적 손실"만

### 3.3 문제 3: 타겟 페르소나 불명확 (Critical Flaw #3)

페르소나별 손익 분석:

헤비 유저 (월 200,000원+ 구매)
├─ 포인트 가치: 엔트리 10,000원, 프리미엄 20,000원
├─ 총 가치: 13,500-25,000원
├─ 구독료: 19,900-29,900원
├─ 손익: -6,400 ~ -4,900원
└─ 판정: 프리미엄만 거의 본전, 여전히 손해

미디엄 유저 (월 50,000원 구매)
├─ 포인트 가치: 2,500-5,000원
├─ 총 가치: 6,000-10,000원
├─ 구독료: 19,900-29,900원
├─ 손익: -13,900 ~ -19,900원
└─ 판정: 큰 손해 (50-70% 손실)

라이트 유저 (월 20,000원 이하)
├─ 포인트 가치: 1,000-2,000원
├─ 총 가치: 4,500-7,000원
├─ 구독료: 19,900-29,900원
├─ 손익: -15,400 ~ -22,900원
└─ 판정: 엄청난 손해 (65-77% 손실)

결론: 누구에게도 "완벽한 선택"이 아님

### 3.4 문제 4: Lock-in 메커니즘 부재 (Critical Flaw #4)

현재 유지 동기 분석:
├─ 강한 유지 동기: 거의 없음
├─ 포인트 누적: 해지 시 소멸 우려만 (부정적 동기)
├─ 레벨 시스템: 구체적 혜택 불명확
└─ 기부: 내가 안 해도 다른 사람이 할 것

구독 해지 가능성이 높은 시점:
├─ 첫 달 종료 시 (30일): "생각보다 별로네"
├─ 3개월 시점: 첫 투표 후 "이게 다야?"
├─ 6개월 시점: 모든 카테고리 경험 후 신선함 소멸
└─ 재정적 압박 발생 시: "굳이 필요한가?" 재고

예상 생존 가능성: 20%

### 5.3 Phase별 개선 전략

Phase 1: 즉시 실행 (생존 확보) - 1-2개월

1. 박스 가치 3배 증폭 ⭐⭐⭐⭐⭐
   엔트리 박스 (3,500원) → 엔트리 박스 (15,000원 공시)
   ├─ 정품 1개 (10,000원): 러브젤 정품 or 소형 토이
   ├─ 샘플 3-5개 (3,000-5,000원): 다양한 카테고리
   └─ 독점 아이템 (2,000원): TBR 한정판

   프리미엄 박스 (5,000원) → 프리미엄 박스 (25,000원 공시)
   ├─ 정품 1개 (15,000-18,000원): 중급 토이 or 고급 러브젤
   ├─ 샘플 5-7개 (5,000-7,000원): 프리미엄 브랜드
   └─ 독점 아이템 (3,000원): 신제품 선행 체험

2. 즉시 사용 크레딧 지급
   ├─ 라이트: 5,000원 (분할)
   ├─ 엔트리: 10,000원 (분할)
   └─ 프리미엄: 15,000원 (분할)

3. 구독자 상시 할인
   ├─ 라이트: 10%
   ├─ 엔트리: 12%
   └─ 프리미엄: 15%

Phase 2: 차별화 구축 (경쟁력 확보) - 3-6개월

4. 무료 배송 혜택
   ├─ 라이트: 월 2회
   ├─ 엔트리: 월 3회
   └─ 프리미엄: 무제한

5. 기부 매칭 시스템
   ├─ 구독자 추가 기부 시 회사가 2배 매칭
   └─ "내 기부가 3배로 증폭" 자기효능감
