# 성인용품 쇼핑몰 성인인증 시스템 연구 보고서

**연구일**: 2026-01-02
**프로젝트**: TeddyBear's Room
**목적**: 포트원 PASS vs KG이니시스 직접 연결 비교 분석

---

## Executive Summary

**핵심 결론**: 성인용품 업종은 대부분의 PG사에서 **제한 업종**으로 분류됩니다. 포트원을 통한 다날 본인인증은 성인용품 업종 등록이 **불가**하며, KG이니시스도 공식적으로 **입점 제한 업종**입니다. 그러나 실제 시장에서는 **NHN KCP**를 통한 본인인증을 사용하는 성인용품 쇼핑몰이 가장 많습니다.

**권장사항**:
1. **우선 순위 1**: 포트원을 통한 **NHN KCP 본인인증** 연동 시도
2. **우선 순위 2**: **NICE평가정보** 직접 계약 문의
3. **백업 플랜**: 결제사와 본인인증을 분리하여 운영

## 3. 실제 시장 현황

### 3.1 성인용품 쇼핑몰의 현실

시장조사 결과, 성인용품 쇼핑몰에서 **NHN KCP**를 사용하는 경우가 가장 많은 것으로 확인됨.

### 3.2 카드사 정책 이슈

- 2022년 1월부터 카드업계가 개인 사업자 온라인 성인용품 쇼핑몰 모니터링 및 결제 차단 시작
- 근거: 여신전문금융업법 제2조 3항 "선량한 풍속을 해치는 품목"
- **모순점**: 쿠팡, 11번가 같은 대형 플랫폼에서는 성인용품 카드결제 가능

### 3.3 결제와 본인인증의 분리

**중요**: 본인인증(성인확인)과 결제(카드 승인)는 **별개의 계약**입니다.

- 본인인증만 별도로 계약 가능
- 결제는 무통장입금/가상계좌 등 대안 사용 가능

## 4. 기술 구현 비교

### 4.1 포트원 경유 (권장)

**장점**:
- 통합 SDK 제공 (`PortOne.requestIdentityVerification()`)
- 다양한 PG사 한 번에 연동
- 무료 가입 (PG사별 건당 비용만 발생)
- 테스트 기능 제공
- Next.js 친화적

**단점**:
- 성인용품 업종 계약 가능 여부 PG사별 협의 필요

**구현 복잡도**: ⭐⭐ (낮음)

```typescript
// 포트원 V2 SDK 연동 예시
import PortOne from "@portone/browser-sdk/v2";

const result = await PortOne.requestIdentityVerification({
  storeId: "store-xxxxx",
  identityVerificationId: `identity-${Date.now()}`,
  channelKey: "channel-key-xxxxx",
});

if (result.code === undefined) {
  // 성공 - 서버에서 인증 정보 조회
  const verification = await fetch(`/api/identity/${result.identityVerificationId}`);
}
```

### 4.2 KG이니시스 직접 연결

**장점**:
- 1번의 계약으로 6개 인증서 사용 가능
- 별도 모듈 설치 불필요 (웹호출 방식)
- 건당 40원 (대용량 시 협의 가능)

**단점**:
- 성인용품 업종 **입점 제한** (공식)
- 계약~서비스 이용까지 약 2주 소요
- 직접 연동 시 복잡도 증가

**구현 복잡도**: ⭐⭐⭐⭐ (높음)

### 4.3 NICE평가정보 직접 계약

**장점**:
- 본인확인 전문 기관
- CI/DI 제공 확실
- 다양한 업종 지원

**단점**:
- 직접 계약 및 연동 필요
- 개발 가이드 복잡
- 업종별 심사 필요 (성인용품 가능 여부 문의 필수)

**구현 복잡도**: ⭐⭐⭐⭐⭐ (매우 높음)

## 7. 최종 권장사항

### 7.1 추천 전략

```
1순위: 포트원 → NHN KCP 본인인증
       ↓ (불가 시)
2순위: 포트원 → KG이니시스 (직접 협의)
       ↓ (불가 시)
3순위: NICE평가정보 직접 계약
       ↓ (불가 시)
4순위: 전문 성인용품 PG (레드커머스 등) 검토
```

### 7.2 즉시 해야 할 일

1. **포트원 고객센터 문의** (cs@portone.io)
   - "성인용품 쇼핑몰 운영 예정, KCP 또는 다른 PG사 본인인증 가능 여부 확인"

2. **NHN KCP 직접 문의** (support@kcp.co.kr)
   - "성인용품 업종 본인인증 서비스 계약 가능 여부"

3. **NICE평가정보 문의** (1588-2486)
   - "성인용품 쇼핑몰 본인확인 서비스 도입 가능 여부"

### 7.3 기술 구현 권장

성인용품 업종 특성상 **포트원 경유**를 권장합니다:

- 통합 SDK로 개발 복잡도 최소화
- PG사 변경 시 코드 수정 최소화
- Next.js + TypeScript 지원
- 기존 TossPayments 결제 연동과 일관성 유지

### 7.4 백업 플랜: 결제와 인증 분리

본인인증이 어려울 경우:

1. **본인인증**: NICE 아이핀 또는 공동인증서 (범용적)
2. **결제**: 무통장입금 / 가상계좌 (카드사 정책 우회)
