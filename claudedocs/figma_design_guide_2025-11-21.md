## 📅 DAY 1: 기초 설정

### Step 1: Figma 프로젝트 생성 (10분)

#### 1-1. 파일 생성
1. [figma.com](https://figma.com) 접속 → 로그인
2. **"+ New design file"** 클릭
3. 파일명: `TeddyBear's Room Design System`

#### 1-2. 페이지 구조
기본 페이지 삭제 후 다음 페이지 생성:

| 페이지명 | 용도 |
|---------|------|
| `01_Colors` | 컬러 시스템 정의 |
| `02_Typography` | 글꼴 시스템 |
| `03_Components` | 재사용 컴포넌트 |
| `04_Home` | 홈페이지 와이어프레임 |
| `05_ProductDetail` | 상품 상세 페이지 |
| `06_Cart` | 장바구니 페이지 |
| `07_MyPage` | 마이페이지 |
| `08_Guidelines` | 디자인 가이드라인 |

#### 1-3. 캔버스 설정
각 페이지에 다음 Frame 생성:

- **Desktop**: 1440px × 900px
- **Tablet**: 768px × 1024px
- **Mobile**: 375px × 667px

**단축키**: `F` (Frame 도구) → 우측에서 사이즈 선택

### Step 2: 컬러 시스템 정의 ⭐ (30분)

#### 2-1. 작업 위치
페이지: `01_Colors`

#### 2-2. Primary Colors (주색상)

| 색상명 | HEX | 용도 |
|--------|-----|------|
| **Primary** | `#D4A574` | 버튼, 헤더, 강조 요소 |
| **Secondary** | `#B4D7E8` | 보조 버튼, 배경 |
| **Accent** | `#F4E4A3` | 이벤트, 특별 강조 |

#### 2-3. Neutral Colors (중립색)

| 색상명 | HEX | 용도 |
|--------|-----|------|
| **Dark** | `#3D3D3D` | 본문 텍스트 |
| **Gray 1** | `#666666` | 보조 텍스트 |
| **Gray 2** | `#999999` | 비활성 상태 |
| **Gray 3** | `#CCCCCC` | 경계선, 구분선 |
| **White** | `#FFFFFF` | 배경 |

#### 2-4. Semantic Colors (의미 색상)

| 색상명 | HEX | 용도 |
|--------|-----|------|
| **Success** | `#4CAF50` | 성공 메시지 |
| **Warning** | `#FFA726` | 경고 메시지 |
| **Error** | `#EF5350` | 오류, 위험 버튼 |
| **Info** | `#29B6F6` | 정보 안내 |

#### 2-5. Figma에서 작업하기

1. **Rectangle** 도구 (단축키: `R`)
2. 크기: 200 × 200px
3. Fill: 해당 컬러 적용
4. 텍스트 추가:
   - 상단: 색상명 (예: "Primary")
   - 중앙: HEX 코드 (예: "#D4A574")
   - 하단: 용도 설명

5. **Local Colors 저장**:
   - Fill 색상 선택 → 우측 패널 4개 점 → "+" → 이름 지정

---

### Step 3: Typography 설정 ⭐ (30분)

#### 3-1. 작업 위치
페이지: `02_Typography`

#### 3-2. 글꼴 시스템

| 용도 | 글꼴 | 크기 | 굵기 | 행간 | 사용처 |
|------|------|------|------|------|--------|
| **Heading 1** | Pretendard Rounded | 48px | Bold (700) | 1.2 | 메인 제목 |
| **Heading 2** | Pretendard Rounded | 32px | Bold (700) | 1.2 | 섹션 제목 |
| **Heading 3** | Pretendard Rounded | 24px | SemiBold (600) | 1.3 | 서브 제목 |
| **Body Large** | Pretendard Rounded | 18px | Regular (400) | 1.6 | 강조 본문 |
| **Body** | Pretendard Rounded | 16px | Regular (400) | 1.6 | 기본 본문 |
| **Body Small** | Pretendard Rounded | 14px | Regular (400) | 1.5 | 보조 텍스트 |
| **Caption** | Pretendard Rounded | 12px | Regular (400) | 1.5 | 라벨, 힌트 |
| **Button** | Pretendard Rounded | 16px | SemiBold (600) | 1.5 | 버튼 텍스트 |

#### 3-3. Figma에서 작업하기

1. **Text** 도구 (단축키: `T`)
2. 우측 패널:
   - Font: `Pretendard Rounded`
   - Size: 위 표 참고
   - Weight: 위 표 참고
   - Line height: 위 표 참고 (단위: px)
3. **Typography Style 저장**:
   - 텍스트 선택 → 우측 상단 4개 점 → "Create style"
   - 이름: 용도명 (예: "Heading 1")

| **Active** | `#A87A3F` | `#FFFFFF` |
| **Disabled** | `#CCCCCC` | `#999999` |

**Figma 작업**:
1. Rectangle: 320 × 56px
2. Fill: Normal 색상
3. Border radius: 12px
4. Text: "장바구니 담기" (Button 스타일, 중앙 정렬)

   - Vertical padding: 16px
6. 복사하여 4가지 상태 만들기
7. **Create Component** (우클릭 → Create component)

## 📝 DAY 6: 가이드라인 문서화

### Step 13: 디자인 가이드라인 (2시간)

#### 작업 위치
페이지: `08_Guidelines`

#### 문서 구조

**1. 컬러 시스템**
- Primary, Secondary, Accent
- Neutral Colors (5단계)
- Semantic Colors

**2. Typography**
- Heading 1-3
- Body Large, Body, Body Small
- Caption, Button

**3. 간격 시스템 (Spacing)**
```
4px  - 최소 단위
8px  - 아이콘 여백
12px - 작은 요소 간격
16px - 기본 Padding
24px - 카드 내부 Padding
32px - 섹션 간 Margin
48px - 큰 섹션 간격
```

**4. Border Radius**
```
8px  - Input, 작은 요소
12px - Button, Card
16px - 큰 컴포넌트
```

**5. Shadow System**
```
Small:  0px 2px 4px rgba(0,0,0,0.1)
Medium: 0px 4px 12px rgba(0,0,0,0.1)
```

## 💡 작업 효율화 팁

### 1. 컴포넌트화 (Component)

**사용법**:
1. 재사용할 요소 선택
2. 우클릭 → "Create component"
3. 다른 페이지에서 "Assets" 패널에서 드래그

**장점**:
- 한 곳 수정하면 모든 곳에서 자동 업데이트
- 일관성 유지

### 2. Auto Layout (자동 정렬)

**사용법**:
- 여러 요소 선택 → `Shift + A`
- 간격, Padding 자동 조정

**언제 쓰나요?**:
- 버튼 내부 (텍스트 + 아이콘)
- 카드 레이아웃
- 헤더/푸터 정렬

### 3. Local Styles 저장

**컬러**:
- Fill 선택 → 우측 4개 점 → "+" → 이름 지정

**Typography**:
- 텍스트 선택 → 우측 상단 4개 점 → "Create style"

**효과**:
- Assets 패널에서 쉽게 재사용
- 일관성 보장

### 4. Figma Plugins 추천

| 플러그인 | 용도 |
|---------|------|
| **Unsplash** | 무료 고품질 이미지 |
| **Iconify** | 무료 아이콘 라이브러리 |
| **Content Reel** | 더미 텍스트/이미지 생성 |
| **Stark** | 접근성 검사 |
