## 🎯 MVP 전략 변경 공지

### 변경 내용
- **이전**: 2-Tier 구독제 (스탠다드 + 프리미엄)
- **현재**: **Single Tier MVP** (TBR 멤버십 단일)

### 변경 사유
```
┌─────────────────────────────────────────────┐
│  MVP 단계에서 단일 tier를 선택한 이유:      │
├─────────────────────────────────────────────┤
│  1. 선택의 역설 → 고객 결정 단순화          │
│  2. YAGNI 원칙 → 필요한 것만 구현           │
│  3. 검증 우선 → 핵심 가치부터 테스트        │
│  4. 운영 효율 → 관리 복잡도 최소화          │
└─────────────────────────────────────────────┘
```

## 📋 현재 시스템 개요

### 🐻 TBR 멤버십 (19,900원/월)
- **타겟**: 모든 멤버십 희망 고객
- **핵심 혜택**: 포인트 5% + 기부 5% + 무료배송(5만원↑) + 쿠폰
- **가입 조건**: TossPayments 정기결제

### ❌ 비회원 (0원)
- **포인트 적립**: 없음 (0%)
- **기부 참여**: 불가
- **무료 배송**: 7만원 이상

## 💡 핵심 마케팅 메시지

> **"포인트 적립 + 기부 참여 + 무료 배송까지!"**

- 월 19,900원으로 모든 핵심 혜택
- 구매할 때마다 5% 포인트 적립
- 구매금액의 5%가 기부로 연결
- 단순하고 명확한 가치 제안

## 🎯 핵심 차별화 요소

### 1. 포인트 적립 차별화
- **비회원**: 0% → 구독 동기 부여
- **멤버십**: 5% → 충성도 보상

### 2. 사회적 가치 연계
- 기부 투표 시스템으로 구독자에게 의미 부여
- 구매가 기부로 연결되는 선순환

### 3. 프라이버시 최우선
- 무지 박스 배송 기본
- 제품명 불공개 배송
