I. 개요
================================================================================

본 문서는 테디베어즈룸 성인용품 쇼핑몰의 구독 멤버십 시스템 최종 설계안입니다.
기존 제안의 재무적 문제점을 해결하고, 고객 가치와 사업 수익성을 균형있게
설계했습니다.

핵심 원칙:
- 박스 자체가 핵심 가치 (크레딧은 보조 수단)
- Tier별 명확한 차별화 (상위 등급일수록 큰 혜택)
- 재무 건전성 확보 (1개월 이탈 시도 흑자)
- 단순하고 이해하기 쉬운 구조

III. 크레딧 시스템 상세 설계
================================================================================

3.1 지급 방식
─────────────────────────────────────────────────────────────

【가입 시 (1회)】
  라이트:   5,000원 즉시 지급
  엔트리:  10,000원 즉시 지급
  프리미엄: 15,000원 즉시 지급

【매월 자동 적립】
  라이트:   매월 1일 2,000원 자동 적립
  엔트리:   매월 1일 3,000원 자동 적립
  프리미엄: 매월 1일 5,000원 자동 적립

【연간 총액】
  라이트:   5,000 + (2,000 × 12) = 29,000원
  엔트리:  10,000 + (3,000 × 12) = 46,000원
  프리미엄: 15,000 + (5,000 × 12) = 75,000원


3.2 Tier별 차별화 명확성
─────────────────────────────────────────────────────────────

라이트 → 엔트리:
  - 크레딧 1.6배 증가 (29K → 46K)
  - 매월 박스 15,000원 가치 제공
  - 할인율 2%p 상승 (10% → 12%)
  - 기부 비율 2%p 상승 (3% → 5%)

엔트리 → 프리미엄:
  - 크레딧 1.6배 증가 (46K → 75K)
  - 박스 가치 1.7배 증가 (15K → 25K)
  - 할인율 3%p 상승 (12% → 15%)
  - 기부 비율 2배 증가 (5% → 10%)
  - 무료 배송 전체 적용

→ 상위 등급일수록 혜택이 기하급수적으로 증가하는 구조


3.3 크레딧 관리 규칙
─────────────────────────────────────────────────────────────

【유효기간】
  - 적립일로부터 2개월
  - 자동 소멸 (유효기간 경과 시)

【누적 규칙】
  - 최대 2개월치까지 누적 가능
  - 예시 (엔트리):
    1월 3,000원 적립 (3월 말까지 유효)
    2월 3,000원 적립 (4월 말까지 유효)
    → 2월 말 보유 크레딧: 6,000원

【사용 조건】
  라이트:   최소 구매액 15,000원 이상
  엔트리:   최소 구매액 20,000원 이상
  프리미엄: 최소 구매액 30,000원 이상

  → 크레딧의 3-6배 실구매 유도 (공짜 구매 방지)

【할인과의 중복】
  - 크레딧 사용 후 할인 적용
  - 예시 (엔트리):
    상품 30,000원
    - 크레딧 3,000원 사용 = 27,000원
    - 12% 할인 적용 = 23,760원 최종 결제

【해지 시 처리】
  - 미사용 크레딧 즉시 소멸
  - 환불 불가 (포인트 성격)

IV. 박스 구성 상세 설계
================================================================================

4.1 엔트리 박스 (15,000원 가치)
─────────────────────────────────────────────────────────────

【구성품】
  1) 메인 정품 1개 (10,000원 가치)
     - 베스트셀러 카테고리에서 선별
     - 예: 프리미엄 윤활제, 인기 성인 토이

  2) 프리미엄 샘플 3개 (5,000원 가치)
     - 신제품 체험용 (2,000원 가치)
     - 럭셔리 브랜드 샘플 (2,000원 가치)
     - 시즌 특별 상품 (1,000원 가치)

【원가 구조】
  정품 원가:      2,000원 (원가율 20%)
  샘플 원가:      1,000원 (원가율 20%)
  포장/배송:        500원
  ─────────────────────────
  총 원가:        3,500원

  → 체감 가치 대비 원가율: 23.3%


4.2 프리미엄 박스 (25,000원 가치)
─────────────────────────────────────────────────────────────

【구성품】
  1) 메인 정품 2개 (18,000원 가치)
     - 고급 라인 제품 (12,000원)
     - 인기 베스트셀러 (6,000원)

  2) 럭셔리 샘플 1개 (7,000원 가치)
     - 초고급 브랜드 협찬품
     - 신제품 독점 체험

【원가 구조】
  정품 원가:      3,600원 (원가율 20%)
  샘플 원가:      1,400원 (원가율 20%)
  프리미엄 포장:  1,000원
  ─────────────────────────
  총 원가:        6,000원

  → 체감 가치 대비 원가율: 24%


4.3 개인화 전략
─────────────────────────────────────────────────────────────

【초기 프리퍼런스 설문 (5문항)】
  1. 선호 카테고리: 기능성 / 럭셔리 / 케어
  2. 경험 수준: 초보 / 중급 / 고급
  3. 민감도 선호: 순한 / 보통 / 강한
  4. 관심 브랜드: 자유 선택
  5. 금기 성분: 알레르기 체크

【큐레이션 비율】
  - 70% 프리퍼런스 반영 (맞춤형)
  - 30% 랜덤 요소 (서프라이즈 효과)

【업데이트】
  - 매 분기 프리퍼런스 재설문 가능
  - 구매 이력 기반 자동 학습

VI. 어뷰징 방지 시스템
================================================================================

6.1 3단계 방어 체계
─────────────────────────────────────────────────────────────

【1단계: 본인인증】
  - 휴대폰 인증 필수
  - 동일 번호 중복 가입 차단
  - 성인 인증 (19세 이상)

【2단계: 재가입 제한】
  - 해지 후 3개월 대기
  - 가입 보너스 1인 1회 (평생)
  - 동일 IP 반복 가입 모니터링

【3단계: 자연스러운 Lock-in】
  - 매월 소액 크레딧 (어뷰징 유인↓)
  - 유효기간 2개월 (장기 누적 불가)
  - 최소 구매액 (공짜 방지)


6.2 어뷰징 시나리오 대응
─────────────────────────────────────────────────────────────

【시나리오 1: "보너스 받고 튀기"】
  행동: 가입 → 보너스 10K → 즉시 해지

  손실:
    크레딧 10K 마진 손실: 4,500원
    박스 원가: 3,000원
    ─────────────────────────
    총 손실: 7,500원

  수익: 19,900원
  순수익: 12,400원 ✅

  → 1개월 이탈도 흑자!


【시나리오 2: "크레딧 모아서 대량 구매 후 해지"】
  행동: 6개월 유지 → 28K 크레딧 누적 → 대량 구매 → 해지

  6개월 수익:
    구독료: 119,400원
    박스 원가: 18,000원
    크레딧 손실: 12,600원
    ─────────────────────────
    순수익: 88,800원 ✅

  → 6개월 유지면 충분히 수익!


【시나리오 3: "가입-해지 반복"】
  방어:
    1) 본인인증 (휴대폰 1대 = 계정 1개)
    2) 해지 후 3개월 재가입 불가
    3) 가입 보너스 평생 1회

  → 실질적으로 불가능


6.3 환불 정책
─────────────────────────────────────────────────────────────

【월 구독】
  - 환불 불가
  - 익월부터 해지 가능
  - 미사용 크레딧 즉시 소멸

【연간 구독】
  - 잔여 기간 비례 환불
  - 단, 할인 혜택 회수
  - 예시:
    연간 215,000원 (10% 할인)
    3개월 사용 후 해지
    환불액 = 215,000 - (19,900 × 3) - (할인 회수)
          = 215,000 - 59,700 - 5,970
          = 149,330원

【크레딧】
  - 해지 즉시 소멸
  - 환불 불가 (포인트 성격)
  - 양도 불가

XII. FAQ (자주 묻는 질문)
================================================================================

Q1. 크레딧은 언제 적립되나요?
A1. 가입 즉시 보너스 크레딧이 지급되며, 매월 1일 정기 크레딧이
    자동으로 적립됩니다.

Q2. 크레딧 유효기간은 얼마나 되나요?
A2. 적립일로부터 2개월입니다. 최대 2개월치까지 누적 가능합니다.

Q3. 크레딧만으로 공짜로 구매할 수 있나요?
A3. 아니요. 최소 구매액 이상 결제 시에만 크레딧을 사용할 수 있습니다.
    (라이트 15K, 엔트리 20K, 프리미엄 30K)

Q4. 박스 내용물을 선택할 수 있나요?
A4. 초기 프리퍼런스 설문을 통해 취향을 반영하지만, 완전한 선택은
    불가합니다. 70% 맞춤형 + 30% 서프라이즈 구성입니다.

Q5. 구독을 해지하면 크레딧은 어떻게 되나요?
A5. 미사용 크레딧은 즉시 소멸되며 환불되지 않습니다.

Q6. Tier를 변경할 수 있나요?
A6. 네. 언제든지 업그레이드 또는 다운그레이드 가능하며, 다음 결제일부터
    적용됩니다.

Q7. 박스를 받고 싶지 않은 달이 있으면?
A7. 라이트 Tier로 다운그레이드하시거나, 구독 일시정지 기능을 이용하세요.
    (최대 2개월)

Q8. 연간 구독 시 할인이 있나요?
A8. Phase 3부터 연간 구독 옵션이 제공되며, 10% 추가 할인됩니다.

Q9. 크레딧과 할인 중복 적용되나요?
A9. 네. 크레딧 사용 후 할인이 적용됩니다.
    예: 30,000원 - 3,000원 크레딧 = 27,000원 → 12% 할인 = 23,760원

Q10. 기부는 어떻게 이루어지나요?
A10. 구독자 투표 시스템을 통해 분기마다 기부처를 선정합니다.
     구독료의 일부(3%/5%/10%)가 자동으로 기부됩니다.

XIII. 부록: 용어 정의
================================================================================

【구독 관련】
  - Tier: 구독 등급 (라이트/엔트리/프리미엄)
  - 빌링키: 자동 결제를 위한 카드 정보 토큰
  - MRR: Monthly Recurring Revenue (월간 반복 수익)
  - ARR: Annual Recurring Revenue (연간 반복 수익)
  - Churn Rate: 이탈률 (해지한 고객 비율)

【재무 관련】
  - LTV: Lifetime Value (고객 생애 가치)
  - CAC: Customer Acquisition Cost (고객 획득 비용)
  - 마진율: (판매가 - 원가) / 판매가 × 100
  - Break-even: 손익분기점

【크레딧 관련】
  - 가입 보너스: 최초 가입 시 1회 지급 크레딧
  - 매월 리워드: 구독 유지 시 매월 적립되는 크레딧
  - 유효기간: 크레딧 사용 가능 기간
  - 소멸: 유효기간 경과로 크레딧 자동 삭제

【박스 관련】
  - BOM: Bill of Materials (구성품 명세서)
  - 큐레이션: 취향 기반 상품 선별
  - 프리퍼런스: 개인 선호도
  - 원가율: 원가 / 판매가 × 100
