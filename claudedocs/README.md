## 📊 정리 기준

### ✅ 보관 기준
1. **최신성**: 최근 작성되고 정보가 up-to-date
2. **실행 가능성**: 바로 활용 가능한 가이드 또는 전략
3. **유일성**: 다른 문서에서 대체 불가능한 고유 정보
4. **완결성**: 독립적으로 완성된 문서

### ❌ 삭제 기준
1. **중복**: 다른 문서에 동일 또는 더 나은 정보 포함
2. **중간 산출물**: 프로세스 기록 또는 중간 보고서
3. **과거 버전**: 업데이트된 최신 문서 존재
4. **미실행 계획**: 실제로 수행되지 않은 계획 문서
