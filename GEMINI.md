# GEMINI.md

This document serves as a guide for understanding and contributing to the **TeddyBear'sRoom** project.

## Project Overview

**TeddyBear'sRoom** is a Next.js-based e-commerce platform combined with a Notion-based documentation system. The goal is to build a full-stack e-commerce website for a teddy bear shop, while using Notion as a single source of truth (SSOT) for documentation and project management.

The project is currently in the initial setup phase. The main Next.js application has not been created yet. The current directory contains helper scripts and documentation generated by an AI assistant.

### Key Features (Planned)

*   **E-commerce Platform**: A fully functional online store built with Next.js.
*   **Subscription Membership**: A recurring subscription model for customers.
*   **Smart Size Recommendation**: A feature to help customers choose the right size.
*   **Donation Voting System**: A system to allow customers to vote for donation recipients.
*   **Notion Integration**: Automation scripts to synchronize content between the Notion workspace and the project repository.

The current directory contains the following:

## Technology Stack

The planned technology stack for this project is:

*   **Frontend**: Next.js 14 (App Router) with TypeScript, Tailwind CSS, and shadcn/ui.
*   **Backend**: Supabase (PostgreSQL) with Prisma and Supabase Auth.
*   **Payments**: TossPayments SDK.
*   **Infrastructure**: Vercel and Vercel Edge CDN.
*   **Design**:
    *   **Colors**: Latte Beige (`#F5E6D3`), Cocoa Brown (`#8D6E63`).
    *   **UI Style**: Rounded corners (`border-radius: 1rem+`).
    *   **Font**: Pretendard Rounded.

## Notion Integration

The project heavily relies on Notion for documentation and project management. The `scripts/notion_helper.py` script is a command-line tool to interact with the Notion API, allowing for batch operations and overcoming some API limitations.

### `notion_helper.py` Usage

This script helps automate interactions with the Notion workspace.

**Prerequisites:**

1.  **Install Dependencies:**
    ```bash
    pip install -r scripts/requirements.txt
    ```
2.  **Set Environment Variable:**
    Set the `NOTION_API_KEY` environment variable with your Notion integration token.

**Commands:**

*   **Read a page:**
    ```bash
    python scripts/notion_helper.py read <page_id>
    ```
*   **Search for a page:**
    ```bash
    python scripts/notion_helper.py search "<query>"
    ```
*   **Append a markdown file to a page:**
    ```bash
    python scripts/notion_helper.py append <page_id> <markdown_file>
    ```
*   **Update page properties:**
    ```bash
    python scripts/notion_helper.py update <page_id> '<json_properties>'
    ```

## Key Architectural Decisions

*   **Security**: Use `pgcrypto` for database-level encryption of sensitive customer data.
*   **Simplicity**: Implement a simple pass/fail logic for the size recommendation feature.
*   **Automation**: Utilize Vercel Cron Jobs to schedule tasks, such as triggering payment processing.
