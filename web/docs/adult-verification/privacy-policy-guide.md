# 성인인증 개인정보처리방침 업데이트 가이드

> 작성일: 2026-01-03
> 버전: 1.0.0
> 문서 목적: 성인인증 시스템 도입에 따른 개인정보처리방침 업데이트 안내

---

## 1. 개요

TeddyBear's Room은 성인용품 판매를 위해 청소년 보호법 및 전자상거래 등에서의 소비자보호에 관한 법률에 따라 **성인인증 시스템**을 운영합니다.

이 문서는 성인인증 도입에 따라 개인정보처리방침에 반영해야 할 내용을 안내합니다.

---

## 2. 본인확인 수탁자 정보

### 2.1 본인확인서비스 제공사

| 항목 | 내용 |
|------|------|
| **수탁 업체명** | 주식회사 포트원 (PortOne Inc.) |
| **수탁 업무 내용** | 휴대폰 본인확인 서비스 제공 |
| **위탁 목적** | 성인(만 19세 이상) 여부 확인 |
| **개인정보 항목** | 성명, 생년월일, 성별, 휴대폰번호, 이동통신사 정보, 연계정보(CI) |
| **보유 및 이용기간** | 본인확인 완료 후 즉시 폐기 (CI 해시만 보관) |

### 2.2 실제 본인확인 처리 기관

| 항목 | 내용 |
|------|------|
| **PG사** | NHN KCP 또는 다날 (DANAL) |
| **처리 방식** | PASS 앱 인증 또는 SMS 인증 |
| **인증 표준** | 한국인터넷진흥원(KISA) 본인확인 표준 준수 |

## 3. 수집 항목 및 보관 기간

### 3.1 수집 항목

| 구분 | 수집 항목 | 수집 목적 | 보관 여부 |
|------|----------|----------|----------|
| **필수** | 생년월일 | 만 19세 이상 판정 | 저장하지 않음 |
| **필수** | 성명 | 본인 확인 | 저장하지 않음 |
| **필수** | 성별 | 본인 확인 | 저장하지 않음 |
| **필수** | 휴대폰번호 | 인증번호 발송 | 저장하지 않음 |
| **필수** | 연계정보(CI) | 중복 가입 방지 | **해시값만 저장** |

### 3.2 저장하는 정보

TeddyBear's Room은 **최소 저장 원칙**에 따라 아래 정보만 저장합니다:

| 저장 항목 | 설명 | 보관 기간 |
|----------|------|----------|
| `isAdultVerified` | 성인인증 완료 여부 (true/false) | 회원 탈퇴 시까지 |
| `adultVerifiedAt` | 인증 완료 일시 | 회원 탈퇴 시까지 |
| `adultVerifyMethod` | 인증 방식 (PHONE) | 회원 탈퇴 시까지 |
| `adultVerifyProvider` | 인증 제공사 (PORTONE_KCP 등) | 회원 탈퇴 시까지 |
| `adultVerifyTxid` | 인증 거래 ID | 회원 탈퇴 시까지 |
| `ciHash` | CI 해시값 (SHA-256) | 회원 탈퇴 시까지 |

### 3.3 저장하지 않는 정보

- 생년월일 원문
- 성명 원문
- 휴대폰번호
- CI 원문 (해시값만 저장)
- DI (저장하지 않음)

## 4. 인증 이벤트 로그

### 4.1 로그 기록 항목

| 로그 항목 | 설명 | 개인정보 여부 |
|----------|------|--------------|

| `createdAt` | 이벤트 발생 시각 | 비식별 정보 |

### 4.2 로그 보관 기간

| 로그 유형 | 보관 기간 | 근거 |
|----------|----------|------|
| 인증 성공 로그 | 1년 | 분쟁 대응 |
| 인증 실패 로그 | 90일 | 오류 분석 |
| 인증 시작 로그 | 30일 | 이탈률 분석 |

## 7. 보안 조치

### 7.1 기술적 보호 조치

- CI 원문 미저장 (SHA-256 해시 + salt 처리)
- 전송 구간 암호화 (TLS 1.3)
- 인증 로그 개인정보 제외
- 중복 콜백 방지

### 7.2 관리적 보호 조치

- 성인인증 데이터 접근 권한 제한 (관리자 전용)
- 인증 로그 접근 로깅
- 정기 보안 점검
